Staff एका किंवा दोन्ही विभागांना शिकवत असल्यास subject assignments त्याप्रमाणे द्यायच्या. Principal च्या स्वतंत्र account मध्ये दोन्ही विभागांचे aggregate reports; office accounts मध्ये त्यांच्या कामापुरत्या edit permissions. Dashboard URL एकाच role साठी स्थिर ठेवून program context account मधून घ्यायचा; बदललेल्या सार्वजनिक login URLs साठी legacy redirects/compatibility तपासायची.

## 6. सर्व सहा semesters चा syllabus

नेव्हिगेशन: **Department → Program / Specialization → Pattern → FY / SY / TY → Semester → Subject → Units / Assessment / Official PDF**.

प्रत्येक विषयात नाव, अधिकृत code, category, credits, theory/practical hours, units, learning outcomes, references आणि internal/external/practical assessment components उपलब्ध स्रोताप्रमाणे असतील. Passing rules आणि maximum marks विषयाच्या अधिकृत योजनेशी जुळवायचे.

## 9. सध्याच्या code मध्ये आवश्यक विस्तार

Repo मध्ये Course, Student.course_id, semester, Faculty.department, Subject आणि role-based login आधीच आहेत. Faculty.department सध्या text आहे; Subject मध्ये curriculum version/NEP credits/units साठी पूर्ण रचना नाही.

विस्तार:

1. Department/Program/Specialization identifiers आणि student enrollment mapping.
2. CurriculumVersion: university, faculty, pattern, effective academic year, source, verification status.
3. CurriculumSubject: semester, official code, category, credits, units आणि assessment components. यापासून चालू वर्षातील subject offering व faculty assignment वेगळे ठेवायचे.
4. Faculty directory व optional linked login identity; अनेक विभाग/subjects ची assignment.
5. Activity व Participation records; approval व evidence metadata.
6. College content/source records: source_url, document_year, checked_at, publication status.
7. सामायिक CSS theme tokens; base template मधील toggle व सुरुवातीचा theme initializer.

संबंधित files: `app/models/`, `app/auth/routes.py`, `app/student/routes.py`, `app/faculty/routes.py`, `app/admin/routes.py`, `app/services/homepage.py`, `app/templates/`, `app/static/css/prava.css`, `app/static/js/app.js`, `config.py`.

## 10. Demo माहितीची अचूक बदली

1. चालू database व uploads चा backup; विद्यमान records आणि seed-generated records ची यादी.
2. Public college facts, courses, संपर्क व verified directory import करणे; source आणि date ठेवणे.
3. ओळखलेल्या demo records ची dependency-aware cleanup; user-created enquiries व इतर नोंदी जपणे.
4. Student/staff accounts कॉलेजच्या अधिकृत roster मधून validation preview सहित import करणे. Username/email/roll-number duplicate errors दाखवणे.
5. Marks/attendance हे अधिकृत student, semester व subject IDs शी reconcile करून घेणे. Website वरच्या जुने निकालांवरून active academic records गृहीत धरायचे नाहीत.
6. Import transaction, audit आणि backup restore verification; total imported/updated/skipped/errors नोंदवणे.
