# Student Module

## Overview

The Student module gives students access to their academic information. Phase 7 focuses on profile management and read-only academic views. Assignment submission and material downloads will be expanded in later phases.

## Features Implemented

- Student dashboard with statistics
- Profile view and edit
- Subject list
- Attendance summary
- Marks summary
- Study materials list with search
- Assignment status overview
- Notifications list
- Role-protected Student routes

## Security

All Student pages require the `student` role. Students can update only their basic profile details. Course, semester, marks, attendance, and assignments remain controlled by Admin or Faculty workflows.
