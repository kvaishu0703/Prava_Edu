# Requirements

## Functional Requirements

- Admin, Faculty, and Student users will log in with role-based access.
- Admin will manage students, faculty, courses, subjects, attendance, marks, study material, assignments, notifications, and reports.
- Faculty will manage assigned subject work such as attendance, marks, materials, assignments, submissions, and notifications.
- Student will view profile, attendance, marks, materials, assignments, submissions, notifications, and password options.

## Technical Requirements

- Frontend: HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons
- Backend: Python, Flask, Jinja2
- Database: SQLite first, MySQL migration later
- ORM: Flask-SQLAlchemy
- Authentication: Flask-Login, Werkzeug password hashing
- Forms: Flask-WTF and WTForms
- Reports: CSV export and print-friendly HTML

## Non-Functional Requirements

- Beginner-friendly code
- Clean and responsive UI
- Secure password handling
- Role-based page protection
- Form validation and helpful errors
- Modular folder structure
