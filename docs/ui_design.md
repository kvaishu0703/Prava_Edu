# UI Design

## Theme

PRAVA uses a clean academic dashboard theme:

- White and light gray background for readability
- Dark navy sidebar for structure
- Purple accent for Admin
- Orange accent for Faculty
- Green accent for Student
- Compact cards and tables for fast scanning

## Layout

The authenticated area uses:

- Top navbar
- Left role sidebar
- Dashboard statistic cards
- Responsive data panels
- Tables for structured records
- Compact notification lists

## Responsive Behavior

On desktop, the sidebar and dashboard content appear side by side. On smaller screens, the sidebar stacks above the dashboard content and navigation links wrap into a compact grid.
