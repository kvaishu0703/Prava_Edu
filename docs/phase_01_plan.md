# Phase 1 Plan

## Purpose

Phase 1 prepares the foundation for PRAVA. The goal is to make sure the Flask project has a clean structure, can run locally, and has enough documentation for a beginner to understand the first step.

## Requirements Covered

- Web-based college academic management system
- Three planned roles: Admin, Faculty, Student
- Python Flask backend
- HTML, CSS, JavaScript, Bootstrap frontend
- SQLite planned for the first database phase
- Modular project structure
- Learning documentation in Marathi

## Marathi Summary

या phase मध्ये project चा पाया तयार केला आहे. अजून database, login आणि dashboard पूर्ण झालेले नाहीत. पण app run होतो, welcome page दिसतो, आणि पुढच्या phases साठी folder structure तयार आहे.
