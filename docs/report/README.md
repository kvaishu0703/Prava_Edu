## Printing

1. Download the relevant **PDF** and open the downloaded file in a PDF reader.
2. Select **A4**, portrait, **Actual Size / 100%**.
3. Print all 45 pages for a complete copy, **1–6** for all personalised front pages, or **1–4** for the cover through Certificate only.
4. Place and Date have separate writing lines. College Seal is aligned opposite Place, with open space beneath it for stamping. Signatures and stamp space are left blank for completion at the college.

PDF fonts are embedded and text remains selectable. View at 100% or above to inspect text clarity. Diagrams and screenshots retain the verified source images; screenshot records reflect the local presentation installation and are not official academic results.

The report includes a five-page Data Dictionary, Use Case Diagram, validation examples, 29 figures, 19 refreshed website screenshots and the results of 63 passing automated tests. Its screenshots do not transfer local database records to a new installation; follow the main [README data-storage instructions](../../README.md) when updating an existing laptop installation.
