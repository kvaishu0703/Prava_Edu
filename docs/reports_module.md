# Reports and Export Module

Phase 13 adds CSV exports and print-friendly report pages.

## Admin Reports

Admin can open the Reports page and download CSV files for:

- Students
- Faculty
- Attendance
- Marks
- Assignments
- Notifications

## Faculty Reports

Faculty can export filtered reports from:

- Attendance Report
- Marks Report

The exported data respects the faculty's assigned subjects.

## Print Support

Report pages include print buttons. Print CSS hides navigation, buttons, filters, and sidebars so tables can be printed cleanly.
